# 문화재 고유명사 검색 회귀 테스트 보고서

## 목적

`경복궁`, `석굴암`, `종묘`처럼 질문에 문화재 이름이 직접 포함되어도 Dense 검색이 관련된 다른 항목을 먼저 반환하는 문제를 별도로 검증한다. 이 테스트는 일반 Dev 25개 평균과 분리한 **고유명사 회귀 세트**다.

## 평가 조건

| 항목 | 값 |
| --- | --- |
| 질문 수 | 5개 문화재 질문 |
| 최종 반환 수 | `top_k=3` |
| 후보 수 | `candidate_k=10` |
| RRF 설정 | `rrf_k=60`, Dense 가중치 1.5, BM25 가중치 1.0 |
| Pinecone | `aks-rag-v1` / `__default__` |
| 임베딩 모델 | `text-embedding-3-small` |
| BM25 코퍼스 | 179,028 청크, SHA-256 `444d9fc8e8da5c845610d0a960a43ef04152dd525087e659c511b72382b317e0` |

실행 시각은 2026-09-01 10:37 (+09:00)이다. 각 질문의 기대 문서는 제목이 같은 원문으로 사람이 지정했다. Pinecone은 읽기 전용으로 검색했으며 벡터를 변경하지 않았다.

## 요약 결과

| 방식 | Hit@1 | Hit@3 | MRR |
| --- | ---: | ---: | ---: |
| Dense | 0.60 (3/5) | 0.80 (4/5) | 0.700 |
| BM25 | 0.80 (4/5) | 0.80 (4/5) | 0.800 |
| Hybrid | **0.80 (4/5)** | **1.00 (5/5)** | **0.900** |

이 고유명사 세트에서는 Hybrid가 Dense보다 1위 정확도를 3/5에서 4/5로 높였고, 모든 기대 원문을 상위 3개 안에서 찾았다.

## 해석

일반 Dev 25개에서는 Dense가 1위 정확도에서 근소하게 앞섰지만, 이름이 직접 들어간 이 고유명사 회귀 세트에서는 Hybrid가 더 좋았다. 특히 `종묘`처럼 표기가 일부 겹치는 항목이 존재하는 경우 BM25 신호가 원문 제목을 찾는 데 도움이 됐다.

반대로 `경복궁 향원정`은 Hybrid에서도 2위에 머물렀다. 따라서 Hybrid만으로 고유명사 문제가 모두 해결됐다고 결론내릴 수 없으며, 제목 일치 보정·문서당 청크 제한·RRF 가중치 조정은 계속 실험해야 한다.
