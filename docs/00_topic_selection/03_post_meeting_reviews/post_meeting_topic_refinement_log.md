## 1. 이행 목적

2차 회의에서는 시간 여건상 최종 주제를 확정하지 않았으며, 다음 두 작업을 우선 후속 정리하기로 했습니다.

1. 방문 도우미와 개인 맞춤형 AI 문화유산 여행 도슨트의 결합 구조 및 범용 LLM 대비 차별성 정리
2. 교육자·문제 출제자를 전제로 하지 않는 교육 주제의 사용자·서비스 흐름 재검토

두 후보를 동시에 확장하면 기준이 섞일 수 있으므로, 아래 순서로 각각 독립 문서를 작성하고 마지막에 같은 기준으로 비교하도록 진행합니다.

## 3. 이번 이행에서 적용한 원칙

- 두 아이디어의 공통 요소가 많아도 문서를 합치지 않고 독립적으로 검토합니다.
- B2B/B2C는 억지로 관리자 화면을 추가하는 기준이 아니라 고객과 사용자 가치를 설명하는 기준으로 사용합니다.
- 수업에서 학습한 RAG·Vector DB·LangChain·LangGraph·환각 방지를 실제 문제 해결 흐름에 연결합니다.
- Fine-tuning은 주제 선정 단계에서 확정하지 않고 기본 LLM·RAG·검증 흐름의 비교 이후 판단합니다.
- 공식 데이터, 출처, 기준일, 라이선스를 데이터와 함께 관리합니다.
- `권장`, `검토`, `가능`이라는 표현을 팀의 `합의`, `선정`, `결정`으로 기록하지 않습니다.

## 4. 다음 단계의 공통 검증 기준

두 후보 모두 전체 데이터를 수집하지 않고 최소 표본으로 먼저 중단·진행 여부를 판정합니다.

| 검증 기준 | 방문·도슨트 후보 | 교육 후보 |
|---|---|---|
| 대상 기관 | 지방 국립박물관 1곳 | 지방 국립박물관 1곳 |
| 최소 유물 | 10점 표본 후 30~50점 확장 판단 | 10점 표본 후 30~50점 확장 판단 |
| 대표 질문 | 사실·추천·비교·답변 불가 질문 | 사실·개념·퀴즈·오답·답변 불가 질문 |
| 추가 데이터 | 운영시간·주차장·정류장 | 역사 해설·핵심 개념·평가 문항 |
| 핵심 기술 검증 | 계획 제약 검사+RAG 대화 연결 | 유물·개념 연결+오답 보충 분기 |
| 권리 검증 | 표시할 유물 이미지의 이용조건 | 유물·기출문제 이미지의 이용조건 |
| 차별성 검증 | 범용 LLM과 동일 시나리오 비교 | 일반 문제풀이 챗봇과 학습 순환 비교 |
