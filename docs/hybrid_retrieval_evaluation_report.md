- **Hit@1**: 기대 문서가 1위에 있는 비율이다. 경복궁처럼 특정 원문을 첫 결과로 보여 주는 사용 경험과 가장 가깝다.

- Hybrid의 전체 시간은 Dense 검색 시간과 BM25 검색·RRF 결합 추가 시간을 합한 값이다. 이번 실행에서 추가 처리 시간은 평균 0.487초였다.

## 해석과 다음 단계

BM25 단독은 정확한 단어가 있는 고유명사 검색의 보조 신호로는 쓸 수 있지만, 이 Dev 세트 전체에서는 Dense 단독보다 크게 낮았다. 따라서 BM25만으로 교체하면 안 된다.

현재 Hybrid는 Hit@3와 MRR이 가장 높고 Hit@1은 Dense와 같으므로, RAG가 상위 3개 근거를 받아 EvidenceChecker가 다시 검토하는 흐름에는 적용 후보가 된다. 현재 평가만으로 확정하지 않고 다음 실험을 진행한다.

1. Dense/BM25 가중치와 `candidate_k`를 Dev가 아닌 Holdout에서도 비교한다.
2. 같은 문서의 청크가 후보를 과도하게 차지하지 않도록 문서당 최대 2개 제한을 별도 실험한다.
3. `경복궁`, `향원정`, `석굴암`, `종묘`처럼 고유명사가 뚜렷한 질문은 회귀 테스트로 유지한다.
4. RRF `relevance` 점수는 cosine 점수와 범위가 다르므로 Dense 기준선 `0.40`을 적용하지 않는다.
