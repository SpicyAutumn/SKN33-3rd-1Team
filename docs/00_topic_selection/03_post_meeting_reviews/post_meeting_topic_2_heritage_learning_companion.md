# 페이지 1/2 — 회의 의견 검토와 주제 재정의

## 1. 결론부터 정리

교육 주제는 **교육자나 문제 출제자를 핵심 사용자에서 제외해도 유지할 수 있습니다.** 다만 기존의 `교육 콘텐츠 제작·검수 플랫폼`이 아니라, 최종 학습자가 직접 사용하는 `문화유산 기반 자기주도 한국사 학습 동반자`로 서비스 중심을 옮겨야 합니다.

중학생 범위는 구현과 평가를 쉽게 만드는 장점이 있지만, 사용자 자체를 중학생으로 고정할 필요는 없습니다. 다음처럼 분리하는 것이 권장됩니다.

```text
사용자 정의
한국사를 기초부터 이해하고 싶은 일반 학습자

내부 난도 기준
중학교 역사 핵심 개념 또는 한국사능력검정시험 기본 수준

콘텐츠 소재
지역박물관의 대표 유물과 공식 역사 자료
```

즉, `중학생`은 구매자나 관리자 역할이 아니라 **설명 난도와 평가 범위를 통제하는 내부 기준**으로 활용할 수 있습니다.

## 2. 권장 주제명

### 문화유산으로 배우는 근거 기반 한국사 학습 동반자

## 3. 한 문장 정의

> 한국사를 기초부터 다시 이해하고 싶은 일반 학습자가 지역박물관의 대표 유물을 출발점으로 시대·사건·인물을 연결해 학습하고, 공식 근거가 포함된 설명·퀴즈·오답 보충학습을 제공받는 RAG 기반 자기주도 학습 서비스

## 4. 회의 의견별 검토 결과

### 의견 1 — 중학생으로 제한하면 사용자가 공무원으로 한정되는가?

**그렇게 볼 필요는 없습니다.** 다만 기존안에서 B2B 핵심 사용자를 박물관 교육 담당자로 두면서, 실제 서비스의 중심이 학습자보다 기관 담당자에게 이동해 보인 것은 타당한 우려입니다.

권장 수정:

- 핵심 사용자를 `한국사 기초 학습이 필요한 일반인`으로 변경
- 중학생 수준은 사용자 신분이 아니라 기본 설명 난도로 사용
- 박물관·교사·공무원은 MVP의 필수 사용자가 아니라 향후 제휴·배포 채널로 이동

### 의견 2 — B2B/B2C를 고려하다가 출제자가 중간 관리자로 보이는 문제

B2B와 B2C를 반드시 동시에 구현할 필요는 없습니다. 교육 프로젝트에서 관리자 승인 기능을 넣는다고 자동으로 비즈니스 가치가 생기는 것도 아닙니다.

권장 수정:

```text
기존안
담당자·출제자 → 콘텐츠 생성·검수 → 중학생에게 제공

변경안
일반 학습자 → 관심 유물·주제 선택 → 학습·퀴즈·오답 보충
                                   ↓
                    공식 근거와 검증 규칙으로 품질 통제
```

문제와 해설은 개발 단계에서 팀이 만든 검증 데이터셋으로 평가하고, 런타임마다 출제자의 승인을 기다리는 기능은 제거합니다.

### 의견 3 — 규정·법령 해석 서비스처럼 일반 사용자/관리자 구분이 필수는 아님

이 설명은 타당합니다. 모든 서비스가 관리자와 일반 사용자로 나뉘어야 하는 것은 아닙니다. B2B/B2C는 서비스 가치를 설명하는 방법이지 필수 화면 구성 규칙이 아닙니다.

이 주제는 다음처럼 설명할 수 있습니다.

- **MVP:** B2C 자기주도 학습 서비스
- **확장 B2B:** 박물관·평생교육기관·에듀테크가 콘텐츠나 체험 프로그램에 도입
- **운영자 기능:** 데이터 등록과 오류 수정에 필요한 최소 기능만 제공

### 의견 4 — 교육자·문제 출제자를 제외하고 방향 유지가 가능한가?

가능합니다. 대신 핵심 가치를 `콘텐츠 제작 효율`에서 다음 세 가지로 바꿉니다.

1. 유물을 보며 시대·사건·인물을 연결하는 **맥락 학습**
2. 공식 자료와 답변을 함께 보여주는 **근거 확인 학습**
3. 오답을 관련 유물과 개념으로 다시 연결하는 **자기주도 보충학습**

## 5. 핵심 사용자와 서비스 구조

### MVP 핵심 사용자 — B2C

> **한국사에 관심은 있지만 시대 흐름과 유물의 의미를 연결하기 어려운 기초 일반 학습자**

예상 이용자는 중학생뿐 아니라 다음을 포함할 수 있습니다.

- 학창 시절 이후 한국사를 다시 배우려는 성인
- 한국사능력검정시험 기본 학습을 시작한 사람
- 박물관 방문 전후에 유물의 배경을 이해하려는 관람객
- 자녀와 함께 역사 내용을 확인하려는 보호자

### 확장 가능한 B2B

- 지역박물관의 온라인·현장 교육 콘텐츠
- 평생학습관과 도서관의 한국사 프로그램
- 에듀테크 기업의 문화유산 기반 학습 모듈

확장 B2B가 없더라도 MVP의 사용자 가치와 기술 검증은 성립합니다.

## 6. 사용자 경험

```text
관심 유물·시대·주제 선택
          ↓
현재 이해도 확인 질문 3~5개
          ↓
공식 유물·역사 자료 Hybrid RAG
          ↓
유물 관찰 포인트 + 시대 맥락 + 핵심 개념 설명
          ↓
근거 확인형 퀴즈
          ↓
오답 개념 추정 → 추가 질문 → 관련 유물로 보충학습
          ↓
오늘 배운 개념과 출처 요약
```

단순히 문제 정답을 맞히는 서비스가 아니라, `유물 → 역사 맥락 → 확인 질문 → 관련 유물`의 순환 구조를 보여주는 것이 차별점입니다.

## 8. 데이터 범위와 수집 방법

| 데이터 | 용도 | 공식 출처 후보 | 주의사항 |
|---|---|---|---|
| 유물 정보 | 관찰·사실 설명 | e뮤지엄, 대상 박물관 | 소장품별 출처·이용조건 저장 |
| 역사 해설 | 시대·사건·인물 연결 | 우리역사넷, 한국사데이터베이스 | 콘텐츠별 이용조건 확인 |
| 난도 기준 | 설명 수준과 개념 범위 | 교육과정 성취기준 | 사용자 신분이 아닌 내부 기준으로 사용 |
| 평가 문항 | 진단·퀴즈 평가 | 팀 제작 문항, 제한적 공식 기출 표본 | 문제 속 이미지 권리 별도 확인 |
| 연결표 | 유물↔시대↔사건↔개념 | 팀 전처리·검수 | 연결 근거와 검수자 기록 |

### 권장 범위

1. 지방 국립박물관 1곳을 선정합니다.
2. 시대 또는 연결 주제 1개를 선택합니다.
3. 대표 유물 30~50점과 관련 역사 해설을 수집합니다.
4. 핵심 개념 10~20개를 정하고 유물과 연결합니다.
5. 진단·학습·답변 불가 질문을 포함한 평가셋을 만듭니다.
6. 원문, 전처리문, 출처 URL, 수집일, 이용조건을 분리 저장합니다.

공식 자료 후보:

- [e뮤지엄](https://emuseum.go.kr/): 전국 박물관 소장품 통합검색과 Open API
- [우리역사넷](https://contents.history.go.kr/front/about/use.do): 역사 콘텐츠 및 이미지별 이용 안내
- [한국사능력검정시험 시험자료실](https://www.historyexam.go.kr/pst/list.do?bbs=dat): 공개 기출문제와 정답표

## 9. 문화유산 이미지 저작권 검토

### 회의 의견에 대한 판단

`국립중앙박물관 자료이므로 모두 상업적으로 사용할 수 있다`고 일괄 판단해서는 안 됩니다. 국립중앙박물관은 저작재산권을 전부 보유한 일부 공공저작물을 자유이용할 수 있다고 안내하지만, 실제 자료에는 공공누리 제1유형부터 상업 이용·변경을 제한하는 다른 유형까지 함께 존재합니다.

- [국립중앙박물관 저작권정책](https://www.museum.go.kr/MUSEUM/contents/M3304000000.do): 박물관이 권리를 전부 보유한 공공저작물의 이용원칙 안내
- [국립중앙박물관 사진자료 이용 안내](https://www.museum.go.kr/MUSEUM/contents/M0508030000.do): 제1유형 외 자료는 상업 이용 또는 변경에 별도 허가가 필요할 수 있음을 안내
- [우리역사넷 이미지 이용 안내](https://contents.history.go.kr/front/about/use.do): 이미지 출처와 공공누리 유형 또는 원 소장처 조건을 개별 확인하도록 안내
- [한국사능력검정시험 시험자료실](https://www.historyexam.go.kr/pst/list.do?bbs=dat): 문항에 사용된 사진 등의 저작권은 원저작자에게 있음을 명시

### 현 단계의 권장 처리

저작권 검토를 프로젝트 주제 선정의 첫 번째 탈락조건으로 둘 필요는 없지만, 데이터 수집 단계부터 다음 필드를 보존해야 합니다.

```text
asset_id
source_page_url
original_rightsholder
license_type
commercial_use_allowed
modification_allowed
attribution_text
verified_at
```

MVP에서는 다음 순서가 안전합니다.

1. 텍스트 중심 RAG와 기능을 먼저 구현합니다.
2. 이미지가 필요하면 개별 자료의 공공누리 유형을 확인합니다.
3. 상업 이용 가능성을 시연하려면 공공누리 제1유형 등 조건이 명확한 자료만 선별합니다.
4. 조건이 불명확하면 이미지를 복제하지 않고 공식 원문 링크 또는 팀 제작 대체 이미지를 사용합니다.
5. 출처표시 문구를 데이터에 저장하고 화면에 노출합니다.

> 저작권은 현 교육 프로젝트에서 후순위 기능일 수 있지만, “확인하지 않아도 되는 문제”는 아닙니다. 특히 포트폴리오에서 상업적 확장성을 설명하려면 항목별 라이선스 관리가 오히려 좋은 설계 근거가 됩니다.

## 10. 권장 시스템 구조

```text
사용자 관심 주제·진단 답변
              ↓
       질문·개념·난도 분류
              ↓
  유물 메타데이터 필터 + Hybrid RAG
              ↓
 유물 관찰·역사 맥락·확인 질문 생성
              ↓
 근거 일치·출처·난도·정답 유일성 검사
       ┌──────┴──────┐
     통과          근거 부족
       ↓               ↓
 학습자 제공        재검색·답변 보류
       ↓
 오답 개념 확인 → 관련 유물 보충학습
```

- **Vector DB·RAG:** 유물 설명, 역사 해설과 사료 검색
- **관계형 DB:** 유물·개념 연결, 문항·정답, 학습 진행상태
- **LangChain:** 적재·검색·프롬프트·구조화 출력
- **LangGraph:** 진단 → 검색 → 설명 → 검증 → 퀴즈 → 보충학습 분기
- **Fine-tuning:** 교육자 문체를 만들기 위한 필수요소로 두지 않고, 충분한 검수 예시가 쌓인 뒤 난도 변환의 일관성을 비교할 때만 검토

## 11. 권장 MVP

> **지방 국립박물관 한 곳의 대표 유물 30~50점과 핵심 역사 개념 10~20개를 연결하여, 일반 기초 학습자에게 수준별 해설·근거 확인형 퀴즈·오답 보충학습을 제공하는 서비스**

| 항목 | 권장 범위 |
|---|---|
| 핵심 사용자 | 한국사 기초를 배우려는 일반인 |
| 내부 난도 기준 | 중학교 역사 핵심 개념 또는 한능검 기본 수준 |
| 기관·유물 | 지방 국립박물관 1곳, 유물 30~50점 |
| 학습 주제 | 시대 또는 연결 주제 1개 |
| 핵심 기능 | 수준 진단, 근거 기반 설명, 퀴즈, 오답 보충 |
| 운영 기능 | 데이터 등록·오류 수정 등 최소 기능 |
| 이미지 | 이용조건이 명확한 자료만 선택 사용 |
| 제외 | 출제자 승인 화면, 학급·성적관리, 전 시험범위, 상업 이용 미확인 이미지 |

## 12. 테스트 및 평가 기준

- 검색 적합성: 정답 근거가 Top-K에 포함되는 비율
- 사실 충실성: 답변과 검색 근거의 일치율
- 출처 표시율과 근거 없는 문장 비율
- 문항 정답 정확도와 정답 유일성
- 기초·일반 설명 난도의 구분 적합성
- 오답 개념 분류 정확도 또는 전문가·팀 합의율
- 관련 유물 추천의 개념 연결 타당성
- 기본 LLM / RAG / RAG+검증 비교

> 교육 주제는 교육자·문제 출제자를 핵심 사용자에서 제외해도 유지할 수 있습니다. 핵심 사용자를 한국사 기초를 배우려는 일반인으로 바꾸고, 중학교 역사나 한능검 기본 수준은 사용자 신분이 아니라 설명 난도와 평가 범위를 통제하는 내부 기준으로 사용합니다. 서비스의 중심은 `유물 관찰 → 역사 맥락 → 근거 확인형 퀴즈 → 오답 개념 보충 → 관련 유물 추천`입니다. 이미지 자료는 국립박물관 자료라는 이유만으로 일괄 상업 이용 가능하다고 판단하지 않고, 자료별 공공누리 유형과 원저작자를 확인해야 합니다.
