## 초기 의사결정 목록

### DEC-001: 프로젝트 세부 주제와 목표 사용자

- 날짜: 2026-08-25
- 상태: 제안
- 참여자: 팀원 A~E
- 배경/문제:
  - 현재 프로젝트 유형만 확정되어 세부 문제와 사용자가 정해지지 않음
  - 수업에서 배운 RAG, Vector DB, LangChain, LangGraph를 활용하면서 공식 데이터를 확보하고 평가할 수 있는 주제가 필요함
- 검토한 선택지:
  - 자격증 조회·탐색
  - 법령 조회 및 해석
  - 자동차 사고 사실·증거 정리
  - 복지 지원금·서비스 추천
  - 집 정리 도우미
  - 문화유산 도슨트
  - 금융정보 챗봇
- 결정:
  - 최종 주제는 아직 확정하지 않음
  - 문화유산 도슨트, 자격증 탐색, 범위를 제한한 복지서비스 추천을 우선 데이터 검증 후보로 선정함
- 결정 근거/실험 결과:
  - 문화유산은 공식 데이터, RAG 적합성, 평가 용이성, 안전성의 균형이 가장 좋을 것으로 예상됨
  - 자격증은 공식 정보와 평가 기준이 명확하지만 단순 조회를 넘어선 사용자 맞춤 탐색이 필요함
  - 복지서비스는 개인화에 적합하지만 자격요건 갱신과 오안내 위험 때문에 지역·대상 범위 제한이 필요함
  - 현재 결과는 공식 사이트와 API 존재 여부를 기준으로 한 사전 검토이며 실제 표본 검색 실험은 수행 전임
- 영향과 후속 작업:
  - 상위 후보별 공식 데이터 30~100건 표본 수집
  - 라이선스, 필수 메타데이터, 설명문 품질과 갱신주기 확인
  - 후보별 대표 질문과 답변 불가 질문 작성 후 기본 검색 실험
  - 검증 통과 후보 중 최종 주제와 핵심 사용자 한 그룹 결정
  - 상세 내용은 `docs/00_topic_selection/` 문서에 기록
- 관련 Issue/PR/문서:
  - `docs/00_topic_selection/topic_selection_summary.md`
  - `docs/00_topic_selection/topic_comparison_report.html`
  - `docs/00_topic_selection/data_feasibility_check.md`
