LLM UNIT PROJECT · TOPIC PROPOSAL

개인 성향 기반
홈 리셋 코치

정리 피로를 느끼는 1인 가구에게, 신뢰할 수 있는 생활위생·분리배출 기준을 바탕으로 오늘 당장 실행 가능한 짧은 정리·청소 계획을 제안하는 근거 기반 AI 도우미

RAG개인화규칙 엔진분리배출출처 표시안전 가이드
한 줄 제안문제·사용자서비스 흐름MVP데이터 신뢰성구현 구조범위·확장

1. 한 줄 제안

“정리할 일이 많아 어디서부터 시작해야 할지 막막한 1인 가구에게, 시간·정리 성향·공간 상태에 맞는 15분 홈 리셋 플랜과 안전한 청소·분리배출 정보를 제공하는 AI 코치”
핵심은 만능 살림 지식이 아니라, 사용자가 지금 실행할 수 있는 한정된 행동을 선택하도록 돕는 것입니다.

2. 해결할 문제와 핵심 사용자

시작 장벽집이 어수선할수록 해야 할 일이 너무 크게 느껴져 시작하지 못합니다.
결정 피로우선순위 부재
일률적 루틴의 한계매일·주간 청소표는 생활 패턴과 공간 상태가 다른 사용자에게 쉽게 실패합니다.
개인화짧은 실행
정보 신뢰 문제재질별 청소법, 소독 필요 여부, 분리배출은 잘못 안내하면 안전·환경 문제가 생길 수 있습니다.
공식 근거안전 우선

핵심 사용자

퇴근 후 정리할 에너지가 부족하고, 10~20분 안에 집 상태를 회복하고 싶은 1인 가구

  • 원룸·오피스텔·소형 아파트 거주자
  • 정리 경험이 적거나 미루는 습관이 있는 사용자
  • 공간을 깔끔하게 유지하고 싶지만 복잡한 루틴은 지속하기 어려운 사용자

설계 원칙

  • 완벽한 청소보다 다음 행동 3개를 명확히 제안
  • 개인 성격 라벨보다 시간·습관·우선순위를 활용
  • 위생·분리배출 답변에는 근거와 기준일 표시
  • 위험하거나 확신할 수 없는 질문은 답변을 제한

3. 사용자가 경험하는 서비스 흐름

01간단 진단가능 시간, 공간, 정리 부담, 우선순위, 지역 입력
02오늘의 목표 설정예: 손님 방문 전 거실 회복 / 주방 악취 줄이기
0315분 플랜정리 → 청소 → 배출 순서의 3~5개 행동 제시
04상황 질문재질·오염·물품을 물으면 근거 기반으로 안내
05실행 기록완료·보류를 반영해 다음 플랜의 난도와 분량 조정
개인화 입력 예시: “오늘 15분 가능”, “버리기 결정이 어렵다”, “시각적으로 깔끔한 책상이 우선”, “서울 ○○구”, “고양이와 함께 산다”.
직업·정확한 주소·민감한 생활 정보는 요구하지 않습니다.

4. 3차 프로젝트 MVP: 작고 선명하게

권장 MVP 정의

“서울의 1인 가구를 대상으로 주방·욕실·책상 중 한 공간의 상태와 가용시간을 입력받아, 15분 정리·청소 플랜과 해당 물품의 분리배출 안내를 제공하는 챗봇”

반드시 구현설명평가 방법
개인화 진단시간·공간·정리 난이도·우선순위 5문항 내외입력 조건이 바뀌면 플랜의 분량·순서가 적절히 달라지는가
15분 실행 플랜공간별 3~5단계, 예상 시간, 완료 체크시간 합계·순서 오류가 없는가 / 사용자 유용성 설문
근거 기반 Q&A청소·소독·분리배출에 출처와 주의사항 표시테스트 질문의 근거 일치율·출처 표시율
안전한 거절·전환제품 혼합, 유해물질, 지역 불명 분리배출은 확답하지 않음위험 질문에 안전 문구·공식 안내 경로를 제시하는가

5. 데이터 신뢰성: 무엇을 어디에 쓸 것인가

데이터가 부족한 주제라는 약점을, 데이터 역할을 명확히 분리하는 방식으로 관리합니다. LLM이 생활 규칙·지역 기준·제품 정보를 지어내지 않도록 설계하는 것이 핵심입니다.

데이터 영역권장 출처·수집 방식처리 방식프로젝트 판단
청소·소독 안전CDC 등 공신력 있는 생활위생 가이드, 제품 라벨 안내문서 청크 + RAG, 원문 링크 표시핵심 데이터
정리 플랜팀이 설계·검수한 공간별 체크리스트와 우선순위 규칙관계형/JSON 규칙 + LLM 설명직접 구축
분리배출한 지역의 지자체 기준과 공공 분리배출 정보정형 테이블 + 기준일·지역 표시지역 한정
친환경 제품환경표지 등 인증 여부를 확인할 수 있는 공개 정보속성 필터링, 특정 구매·가격 추천은 제외보조 기능
가구 배치·사진 분석방 사진·치수·객체 인식 데이터 필요비전 모델·공간 추론4차로 분리

주신 데이터 링크의 올바른 활용

생활화학제품 데이터는 제품군·안전 관리의 분류 참고로, 녹색제품 데이터는 환경표지 여부의 보조 근거로 활용할 수 있습니다. 둘 다 특정 상품의 현재 가격·재고·성능을 추천하는 데이터는 아닙니다.

신뢰도 표시 규칙

답변마다 출처 / 기준일 / 적용 지역 / 확실성을 함께 노출합니다. 지역이 확인되지 않으면 “지자체 기준 확인 필요”로 전환하고, 제품 화학성분 혼합·의료적 판단은 안내하지 않습니다.

6. 권장 구현 구조

[사용자 입력] 시간 · 공간 · 정리 성향 · 우선순위 · 지역 · 생활 조건 │ ▼ [플랜 관리자 / LangGraph] ┌───────────────┼────────────────┐ ▼ ▼ ▼ [정리 규칙 DB] [안전 가이드 RAG] [분리배출 테이블] 시간·공간별 출처 문서 검색 지역·품목·배출법 행동 순서 계산 + 인용문 반환 + 기준일 반환 └───────────────┼────────────────┘ ▼ [제약 검사 + 안전 필터] 시간 초과 / 위험 표현 / 지역 불일치 확인 ▼ [행동 플랜 + 근거 + 주의사항] 완료 기록 → 다음 플랜 난도 조절

LLM의 역할은 사용자의 맥락을 이해해 플랜을 설명하고 대화 흐름을 이어가는 것입니다. 시간 합산, 분리배출 규칙 적용, 안전 제한은 코드와 정형 데이터가 담당합니다.

7. 이번 프로젝트에서 제외할 것과 4차 확장

3차에서 의도적으로 제외

  • 전국 모든 지자체의 분리배출 완전 지원
  • 특정 쇼핑몰의 가격·재고·구매 링크 추천
  • 집 사진 업로드 기반의 정리 상태 자동 판정
  • 가구 치수 기반의 배치 시뮬레이션
  • 전문 청소·화학물질·해충·의료 상황의 판단

4차 프로젝트 확장 로드맵

  • 방 사진의 얼굴·문서·주소를 가린 뒤 clutter 영역 인식
  • 가구 치수·창문·문 위치를 반영한 배치 후보 생성
  • 수납용품·친환경 제품의 인증·예산·규격 기반 비교
  • 분리배출 지역을 다수 지자체로 확대
  • 실행 이력을 통한 장기 루틴·소비 습관 피드백
